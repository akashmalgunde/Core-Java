# Core Java Practice

This repository contains structured Core Java programs organized topic-wise for better understanding and practice.

## 📚 Topics Covered
- Basics (Variables, Data Types, Operators)
- Control Statements (if-else, switch, loops)
- Arrays and Strings
- Object-Oriented Programming (OOP)
- Methods and Constructors
- Exception Handling
- File Handling
- Multithreading
- Collections Framework

## 🎯 Purpose
The goal of this repository is to strengthen Core Java concepts through hands-on coding and problem-solving. Each folder represents a specific topic with simple to intermediate level programs.

## 🚀 Outcome
Improved problem-solving skills, better understanding of Java fundamentals, and preparation for technical interviews and backend development.
